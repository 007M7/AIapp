## 1. 目标与双端边界

App 面向同一类手办用户，承接五域档案馆／编辑室体验，与小程序共享账号下的角色、设备和资产事实。iPhone 初版已存在，继续完善现有 SwiftUI 工程；安卓不因本 PRD 自动选择 Kotlin、Flutter 或 React Native，也不为共用页面而改写已有 iOS。

| 能力 | iPhone MVP1 已定 | 安卓整理目标／状态 |
|---|---|---|
| 五域及开箱 | D-13 同构五域 | 同构五域，未实现 |
| BLE 配网 | D-13；现有 Security 1 移植，无 PoP | 目标沿用设备协议；权限及传输实现待设计 |
| 文字回合、文本＋音频、按键停止播放 | D-13；客户端已有 | 建议与 iPhone 同范围，待评审，无代码 |
| 正式登录 | Q-88 待决；开发期手填 token | 复用同一账号体系，平台接入待定 |
| 支付／远程推送／小组件／OTA／实时语音 WS | D-13 裁出本期 | 不默认加入；若需要扩大范围须另行评审 |
| 契约／出生证／记忆／退出删除 | 共用产品目标，未闭环 | 同语义，未实现 |

本地通知的 UI／权限入口不等于远程推送已实现，也不代表已有定时任务；文字回合不承诺设备同步出声。V1 无硬件音量／灯效控制。安卓与 iPhone 同期推进 MVP，各自提供测试包和验收记录；最低系统版本、分发渠道、技术路线与正式登录待 Q-89／Q-88。

## 3. 核心场景与异常要求

| 场景 | 成功结果 | 异常、取消与恢复 |
|---|---|---|
| 浏览与账号 | 允许公开内容可浏览；私有数据只属于当前账号 | 未配置、未登录、token 失效与请求失败分别呈现；不吞错误伪装为空列表 |
| 绑定／配网 | 认领与联网状态分别确认；返回设备页能重读 | 无权限／蓝牙关闭给系统恢复路径；密码错可 reset 重试；断连重建安全会话；相机拒绝时可手输 SN |
| 开箱 | 步骤断点保存，命名／入册／签署在服务端可重读 | 每步可跳过；恢复草稿；未成功认主时不能显示真实认主成功；没有设备不虚构出声 |
| 文字回合 | 同一角色收回复并可停止播放，记录可重读 | 请求失败允许重试；取消后不继续播放；音频缺失／格式不支持给可理解反馈；重复发送契约实现前明确 |
| 记忆 | 用户查看、纠错、删除、封存后跨端一致 | 取消不修改；服务失败不提前宣称成功；封存与删除语义分开 |
| 包装载／试听 | 官方包版本实际进入资产；试听可播放 | 网络／权益／音频错误可恢复；不把未付费项目显示为已获得 |
| 分享／退出删除 | 分享不含私人记忆；退出与数据删除实际生效 | 系统分享取消无副作用；注销／角色删除明确对象和范围，失败可重试 |

## 4. 双端技术与非代码归属

产品与内容共用：五域命名、承诺文本、官方首包、语气库、空态、隐私说明、分享卡资产及服务边界。数据、API、账号归属共用 14，不在安卓另建一套后端。

平台实现分别维护：BLE／权限生命周期、音频播放与停止、系统分享、深链、登录 SDK、签名打包和分发。安卓与 iOS 的代码复用程度在架构评审后决定；共用产品定义不等于共用源代码。

iOS 实现保留 `ios/`；安卓工程目录建议为 `android/`，实际选型后再建。`prototype/` 属于设计 demo，`docs/` 属于非代码资料；原型生成器与测试脚本仍是代码。构建产物 `ios/dist/` 是被忽略的本地产物，不当作源码或发布证明。

内容待补沿用 21 §5；App 特有项为正式图标、系统权限说明、登录／账号切换说明、音频失败与停止反馈、安装与测试说明。承诺类文本的修改仍先回 17 正本。

## 最新用户方向：3D 展示与玩法触发（2026-10-03）

小鲸基础性格为嘴硬心软、贪吃爱摸鱼、会吐槽，基础关系为日常搭子。首版以 3D 小鲸形象为展示主体，用户建议 Blender 制作并支持 360 度环绕观察；不以常驻聊天窗口或用户主动输入作为核心体验。用户希望游戏事件及日常时间 hook 让角色发声，玩法需深度设计。具体模型资产、渲染技术、玩法、发声终端、前后台调度与实体播报尚未确定。本条覆盖原文关于首页聊天主体验的描述，不把旧 D-13 的文字回合能力自动当新版主入口；既有实现与历史证据保留。设备冻结及远程推送等范围不因产品讨论自动解除。设计与待办见 app-first-character-content.md、app-frontend-content-plan.md、app-todo.md。

场景讨论补充：用户确认一期“出门”主要是手机中的数字随行及玩法外出，并以《旅行青蛙》类比异步陪伴；陪伴与真实感由持续生活、事件、用户参与及共同经历承载，不要求纯聊天。具体玩法与同步执行仍待批次 1 深入设计。


## 2026-10-11 设备交互基线补充

新硬件基线为 upstream 69312fd、定制板 fw 0.5.0-idf61。详见 [App 与实体手办交互基线](app-device-interaction-baseline.md)，该补充优先于本文旧板实现描述；既有功能范围不因硬件更新自动扩大。

BLE 仅配 WiFi，后续业务走云端/WSS；WiFi 配置、业务连接和账号绑定分别确认。账号/归属/角色档案由云端持有，设备保存本地 WiFi/身份配置。采用“能量”呈现方向，但真实供电状态与未来玩法数值分开；USB 检测仅支持接电源表现，不证明正在充电。

当前无活动 20 分钟深睡（USB 下也执行），仅实体键唤醒，不能远程/BLE/定时唤醒。空闲状态尚不接受通用事件音频，hook 需要新增事件播放状态/命令/回执；音量有底层函数，滑杆仍缺命令/回执/NVS；双 OTA 槽仅为存储基础，下载/校验/切换/健康确认/回滚尚未实现。桌面保活、电池节能、定时唤醒、音量和 OTA 的具体批次待评审，不把讨论方案标成已交付。
