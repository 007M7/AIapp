# 管理页面设计

2026-10-12 · 页面由真实管理 API 驱动，数据与审批状态不由前端伪造。

桌面左侧导航，主区顶栏含当前身份、权限角色、刷新、退出；本地身份试用单独标识。窄屏导航变为可滚动区域，表单单列。使用浅底、深蓝文字、蓝紫主按钮；审批和危险操作有语义色及文字，不只靠颜色。

工作台展示实际计数与流程入口。素材／角色／内容／事件采用同一列表－编辑布局：类型筛选、版本状态、详情，表单明确引用具体版本；保存产生新版本。素材有图片预览或 GLB 文件信息。引用选择显示名称＋版本＋审批状态。

审核页显示完整版本载荷、引用和作者，先看内容再填写理由执行通过／驳回。发布页用批准版本多选、环境、发布名称和原因，确认后服务端生成依赖快照；历史卡显示环境指针，回退与下架均确认。消费预览只读取当前 release，角色图＋正文＋事件操作，实际结果写执行记录。

操作记录显示时间、身份、动作、目标、结果、请求标识及原因，可加载下一页。管理员页提供用户名、密码、角色及启停，密码输入不回显或保留；预览身份只展示、不可当真实生产账号。

状态矩阵：加载显示进行中；空态给对应创建入口；读取失败给重试；写失败保留表单；401 回登录；403 保留上下文并说明权限；409 要求刷新，不能自动覆盖；成功后重读服务端事实。危险动作支持取消，取消不发请求。原生 dialog、label、键盘焦点、aria-live 错误反馈；长名称和 ID 可换行。

页面到需求：素材 ADM-01；编辑 ADM-02；审核 ADM-03；发布 ADM-04/06；消费预览 ADM-05；管理员 ADM-07；操作记录／工作台 ADM-08。统一默认空库；可选引导样例必须由脚本明确创建，禁止假数据混入正式运行。
