# 20 · MVP1 素材物料与美术需求清单

> **依据**:`19-miniprogram-ia-prd.md` v1.2(5 Tab + 5 分包 + 30 个页面 + 6 类流程 + 8 条验收标准)、`17` §3.1/§3.4(物料层与承诺文本)、`18` v1.2(设备侧冻结:按键只剩两个动作)、`15` §6.5/§6.6(话术禁令与合规矩阵)、`14` 红线#3(禁好感度数值)。
> **本文用途**:交给美术/设计侧的**需求清单**——只列"要什么、用在哪、要多少、什么规格、什么优先级"。
> **边界**:手办**本体造型、外壳、包装主体**由设计侧主导,不在本文范围;本文覆盖 **小程序数字素材 + 配套印刷/实体物料 + 音频**。
> **优先级**:`P0` = MVP1 首发必需(缺了页面不完整);`P1` = 可延后、不阻塞首发(PRD 已标注 P1 的页面);`P2` = 二期。
> **规格总原则**(来自 PRD §5.1/§8):主包 ≤1.5 MB、分包各 ≤800 KB、总包 ≤5 MB;**图片与音频全部走 CDN,不入包**;夜间模式跟随系统 → **所有成套素材需双色调**。

## 9. 必须写进设计 brief 的六条美术红线

1. **禁数值化**:不出现进度条、好感度表、数值条、红点;`14` 红线#3 是产品定义级禁令,不是风格偏好。
2. **成人向,不做幼态**:主战场是 18–34 岁女性为主的潮玩/谷子人群(`13` 已复核);**禁用儿童向画风**(`15` §6.6:不做未成年人向)。
3. **承诺类物料必须逐字对齐 `17` §3.4**:出生证、契约卡、承诺页、停服保留清单卡,**文案不由美术改写**。
4. **不出现 AI 卖点式表达**:不画"AI 大脑""智能光环""科技感粒子"来暗示智能;AI 是定语不是主语(`16` 筛选器 Q7)。
5. **分享素材默认脱敏**:分享卡与 Web 落地页里,用户发言一律呈现为"你",不带原文、不带昵称(PRD §8 隐私)。
6. **可访问性与双色调**:对比度/字号遵循微信规范;夜间模式跟随系统,所有成套素材需提供深色版。

## 12. 建议的三批交付顺序

**第一批(可立即开工,不依赖任何待决项)**
A1 规范 → A2 Tab 图标 → A3 图标集 → A4 状态件 → 5 个 Tab 空态(B1~B3)→ B5 配网五态 → D1 按键两动作动图 → D2 加载动效。
> 这批是"页面能搭起来"的最小集,也是所有后续素材的视觉基准。

**第二批(依赖承诺文本定稿后)**
B9 出生证 → B10 契约卡 → B11 签署记录 → B12 承诺页 → B13 退出删除页 → C1~C4 分享物料 → G1/G2/G5 文案 → F1~F7 印刷件。
> 这批是"信任与合规"物料,也是本产品唯一的传播资产,不能赶工。

**第三批(可与内容排期并行)**
B15/B16 商店视觉 → B17 社区视觉组 → B14 年历 → C5/C7 Web 版式 → D4/D5 动效 → E1 试听 → E3 音效规范。

## 13. 一句话总结

**MVP1 的素材分两半:一半是"页面能跑起来"的常规 UI 资产(约 40 个图标 + 18 张插画 + 5 个动效),一半是"信任与承诺"的物料(出生证、契约卡、停服保留清单、恢复卡、承诺页)。** 前一半按常规排期做;**后一半必须与 `17` §3.4 的文本逐字对齐、且不能由美术改写**——它们不是装饰,是本产品的核心承诺在用户手上的形态。
